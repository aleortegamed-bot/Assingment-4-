Chapter 3 – Evaluating Hardware

Assignment 4: Hardware Evaluation Page

A look at four core components of a computer, what each one does, and why it matters for everyday performance.

Comparison table

ComponentDescriptionImportance
CPU The Central Processing Unit is the "brain" of the computer. It executes program instructions and performs calculations. Determines how fast the computer runs programs and handles multitasking. A slow CPU makes everything feel sluggish.
RAM Random Access Memory is fast, temporary memory that holds the data and programs currently in use. More RAM lets you keep more apps and browser tabs open without slowdowns. Its contents are erased when the power is off.
SSD A Solid State Drive is permanent storage built from flash memory chips, with no moving parts. Stores the operating system, programs, and files. It boots the computer and opens apps much faster than a traditional hard drive.
GPU The Graphics Processing Unit is a processor specialized in drawing images, video, and 3D graphics. Essential for gaming, video editing, 3D design, and AI workloads. It also takes graphics work off the CPU.

Component details

CPU – Central Processing Unit

The CPU reads instructions from programs and carries them out, billions of times per second. Its speed depends on the number of cores (how many tasks it can run in parallel) and its clock speed in GHz.

What to evaluate: number of cores and threads, clock speed, cache size, and power consumption. Examples: Intel Core i5/i7, AMD Ryzen 5/7.

RAM – Random Access Memory

RAM acts as the computer's short-term workspace. When you open a program, it is loaded from storage into RAM so the CPU can reach it quickly. When RAM fills up, the system slows down.

What to evaluate: capacity (8 GB is a minimum today; 16 GB is comfortable), type (DDR4 or DDR5), and speed in MHz.

SSD – Solid State Drive

An SSD keeps your data even when the computer is off. Because it has no spinning parts, it is faster, quieter, more shock-resistant, and uses less power than a hard disk drive (HDD).

What to evaluate: capacity (256 GB to 2 TB), interface (SATA or NVMe), and read/write speeds. NVMe drives are several times faster than SATA.

GPU – Graphics Processing Unit

A GPU has thousands of small cores that work in parallel, which makes it ideal for rendering graphics and for machine learning. It can be built into the CPU (integrated) or be a separate card (dedicated).

What to evaluate: video memory (VRAM), number of cores, supported resolution, and cooling. Examples: NVIDIA GeForce RTX, AMD Radeon RX.

Conclusion

These four components work as a team: the CPU processes, the RAM provides fast working space, the SSD stores data permanently, and the GPU handles graphics. A slow part can bottleneck the others, so the right balance depends on how the computer will be used: office work needs a solid CPU, RAM, and SSD, while gaming and video editing also need a strong GPU.
